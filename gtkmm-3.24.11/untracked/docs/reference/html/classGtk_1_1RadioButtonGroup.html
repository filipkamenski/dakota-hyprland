Detailed Description

RadioButtonGroup, identifier for RadioButtons.

To set up this RadioButtonGroup, construct a RadioButtonGroup and then pass it to the constructor of all radio items. You do not need to keep the RadioButtonGroup beyond the initial construction. It should not be instantiated with new, and it will be invalid after the RadioButtons have been deleted.
